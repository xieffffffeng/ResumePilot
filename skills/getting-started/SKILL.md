# 基础工作流

- 只使用用户资料和岗位 JD 中出现的事实；缺少的信息保留为空或明确标记，不推测学校、公司、时间、成绩和指标。
- 先识别岗位目标和关键要求，再选择最相关的教育、经历、项目、论文和技能。
- 输出内容应服务于岗位匹配、简历修改或面试准备，给出可执行的下一步建议。
- 保持中文表达简洁、可核验、有量化证据时优先使用原始量化证据。
- 生成结构化结果时严格遵守调用方指定的 JSON 字段和数据类型，不添加解释性文字。
